# Implementation contract

All `/api/v1` JSON responses use `{data: T, meta?: object}`. Errors use `{error:{code,message,details?}}`. Cookie credentials on every fetch; send `X-CSRF-Token` for mutations, obtained from GET `/auth/session` (anonymous allowed). API base same-origin; Vite proxies `/api` to 127.0.0.1:8000.

## Authentication
GET /auth/session => `{user: null|{id,name,email,role,organisation_id},csrf_token:string}`. POST /auth/register `{name,email,password}` (minimum 12 characters), POST /auth/login `{email,password}` => session shape. POST /auth/logout. Registration creates private organisation and owner role; no first-user public admin escalation. Admin managed via CLI. PATCH /admin/settings requires admin.

## Properties
GET /buildings => Property[]. POST /buildings / PATCH /buildings/{id} => Property. GET /buildings/{id} => Property including measurements/observations.
Property: `{id,property_code,name,property_type:'residential'|'commercial'|'apartment'|'community',locality,latitude,longitude,timezone,geometry:null|GeoJSONPolygon,geometry_source:'manual'|'osm'|'microsoft',footprint_area_m2:null|number,effective_catchment_m2:null|number,measurement_status:'unverified'|'user_entered'|'field_verified',roof_material:'rcc'|'concrete'|'metal'|'tile'|'other',runoff_coefficient:null|number,coefficient_source:string,first_flush_mm:number,collection_efficiency:number,tank_capacity_l:number,current_storage_l:number,daily_demand_l:number,storage_measured_at:string,storage_status:'estimated'|'measured',available_space_m2:null|number,share_aggregate:boolean,notes:string,created_at}`. Create requires name/type/coordinates; remaining fields optional with transparent assumptions. Runoff coefficient required before modelling, never inferred without disclosed source. Null catchment blocks modelling. Geometry footprint never auto-verifies catchment.
POST /buildings/{id}/measurements `{area_m2,method,evidence_note,measured_at,status:'user_entered'|'field_verified'}` => Property. Field verification requires method/evidence. POST /buildings/{id}/photos multipart file => metadata. GET /buildings/{id}/photos/{photo_id} private.
GET /buildings/lookup?latitude=&longitude=&provider=osm|microsoft => `{features:GeoJSONFeature[],provider,retrieved_at,attribution,limitations}`. Bounded lookup. POST /buildings/geometry `{geometry}` => `{area_m2,centroid,crs,method}`.

## Weather
GET /weather/forecast?property_id= (or latitude,longitude,timezone)&days=7&refresh=false => `{id,provider,retrieved_at,issue_time:null|string,timezone,latitude,longitude,model_latitude,model_longitude,spatial_resolution,stale:boolean,cache:boolean,attribution,hourly:[{time,precipitation_mm,probability_pct:null|number,rain_mm,showers_mm}],daily:[{date,precipitation_mm,probability_pct,precipitation_hours}],tomorrow:{date,precipitation_mm,probability_pct,hourly:[]}}`.
GET /weather/tomorrow => tomorrow + provider metadata. GET /weather/historical?property_id=&start_date=&end_date=&provider=open_meteo|imd => `{provider,data_kind,coverage,spatial_resolution,attribution,daily:[{date,precipitation_mm}],annual:[{year,total_mm,complete}],monthly:[{month,mean_mm}],seasonal,limitations}`. IMD requires approved local dataset/configuration. /weather/status /data-sources/status => provider status array.

## Calculation / WaterTwin
POST /rainwater/calculate `{area_m2,runoff_coefficient,first_flush_mm,collection_efficiency,rainfall_mm}` => breakdown.
POST /rainwater/forecast `{property_id,days:7}` => `{id,property_id,forecast,calculation:Simulation,assumptions,confidence,readiness}` persisted immutable snapshot; GET /rainwater/history/{property_id} => saved snapshots.
Simulation: `{rainfall_mm,rainfall_volume_l,gross_runoff_l,first_flush_l,collection_loss_l,net_inflow_l,initial_storage_l,final_storage_l,overflow_l,water_supplied_l,unmet_demand_l,demand_l,capacity_l,balance_error_l,events:[...],hourly:[{time,rainfall_mm,gross_runoff_l,first_flush_l,collection_loss_l,net_inflow_l,storage_l,overflow_l,water_supplied_l,unmet_demand_l,event_id}],daily:[{date,rainfall_mm,net_inflow_l,storage_l,overflow_l,water_supplied_l,unmet_demand_l}]}`.
GET /storage/{property_id} => `{property,tank,observations,latest_simulation}`. POST /storage/observations `{property_id,kind:'storage'|'rainfall'|'collection'|'overflow'|'first_flush'|'maintenance',measured_at,interval_start?,interval_end?,value?,unit:'L'|'mm'|'note',method,reliability:'measured'|'estimated',notes}` => observation. POST /storage/optimise `{property_id,capacities_l:[...],start_date,end_date,cost_per_l_inr?:number,provider?:'open_meteo'|'imd'}` => `{historical,comparisons:[{capacity_l,cost_inr,simulation}],recommended_range_l,reasons,limitations}`. Uses actual retrieved daily history, no production fixtures. GET /calibration/{property_id} => `{observations,accuracy,eligibility,records,limitations}`.

## Recommendations / community / assistant
POST /recommendations/generate `{property_id}` => `{id,property_id,items:[{type,title,reason,status,assumptions,missing_information}],readiness,limitations}`. GET /recommendations/{property_id} => saved recommendations.
GET /dashboard/locality?locality=&property_type= => `{locality,registered_count,residential_count,commercial_count,verified_rooftop_m2,unverified_count,storage_capacity_l,forecast_potential_l:null|number,overflow_l:null|number,properties:Property[],limitations}`. Scoped to own org; municipal endpoint requires municipal/admin and opt-in aggregates only, no private property geometry.
POST /assistant/chat `{property_id?:string,message:string}` => `{answer,mode:'deterministic'|'ai_gateway',sources,limitations}` authorised backend context retrieved before optional LLM. No unsupported factual calculations.
GET /reports => report metadata. POST /reports `{property_id}` => report metadata. GET /reports/{id}/download?format=pdf|html => downloadable private assessment with snapshots/provenance/assumptions. GET /admin/settings => nonsecret configuration + current user role; PATCH admin settings limited allowlist.

## Expanded location and daily-operation contract

Properties also retain country, state, district, city/village, postcode, location source and administrative identifiers. Locations use independently sourced district/search/reverse endpoints. Supply/consumption, maintenance, quality and budget APIs preserve organisation permissions and the same data/error envelope. WaterTwin history/storage responses expose stale, stale_reasons, inputs_changed and horizon_days while retaining the stored snapshot. See API_DOCUMENTATION.md for complete endpoint parameters; docs/WATER_OPERATIONS.md records interval and investment assumptions.
